# Audio Assets for Rahul weds Radhika Wedding Website

To use custom recorded folk audio files instead of the automatic Web Audio synthesizer:

1. Place your background fusion track here:
   Filename: bg-fusion.mp3
   Recommended format: MP3 / OGG, compressed < 400 KB, seamless loop.

2. Place your acoustic Dhol hit / roll sound effects here:
   Filename: dhol-hit.mp3
   Recommended format: MP3, ~50 KB.

The site is built with an automatic client-side Web Audio synthesizer fallback, so all festive dhol hits, dhol rolls, and ambient folk drones work immediately even before custom audio files are dropped in.
